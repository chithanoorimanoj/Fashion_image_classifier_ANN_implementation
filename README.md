## Project Overview
This project focuses on classifying fashion product images using two different approaches:

1. **Traditional Machine Learning:** Random Forest Classifier.
2. **Artificial Neural Network (ANN):** Neural network-based image classification.

The main objective is to understand the differences between traditional Machine Learning and ANN in image classification. I also developed an interactive Streamlit application to make
image predictions.

## Technologies Used

## Project Implementation

### 1. Before ANN – Random Forest
- Implemented Random Forest for fashion image classification.
- Performed image preprocessing and feature extraction.
- Trained the model to classify fashion images.

### 2. After ANN – Neural Network
- Implemented an Artificial Neural Network.
- Explored how neural networks learn complex patterns from image features.
- Trained the ANN model for fashion image classification.

### 3. Streamlit Application
- Developed an interactive web application.
- Upload fashion images in JPG, JPEG, and PNG formats.
- Display model predictions through a simple user interface.

## Model Comparison

| Random Forest |           | ANN |
| Traditional ML algorithm  | Neural network approach |
| Uses input image features | Learns patterns through network layers |
| Tree-based model          | Neuron-based architecture |
| Ensemble learning         | Forward and backward propagation |
